## Wails Dev 绑定生成竞态修复

- 风险结论：`wails dev` 会在前端 dev server 已启动后重新生成 `frontend/wailsjs`，Vite 可能在 `models.ts` 被短暂删除时预转换源码，触发 `/wailsjs/go/models.ts` 缺失的 Pre-transform error。
- 处理：在 `frontend/vite.config.js` 增加 dev-only `wails-generated-file-retry` 插件，仅对 `frontend/wailsjs/**/*.js|ts` 的 `ENOENT` 读取做 2 秒短重试，避免扩大到生产 build 或普通源码。
- 验证：新增 `storyCatalog` 静态约束测试；`node --test src/features/design-system/storyCatalog.test.mjs`、`npm run typecheck`、`npm run build` 通过；`./scripts/wails-cli.sh dev` 已越过原失败点，未再出现 `/wailsjs/go/models.ts` Pre-transform error。

## Wails Dev 单实例启动修复

- 根因：正式版 `/Applications/GetTokens.app` 运行时持有 `SingleInstanceLock` 的 `com.linhay.gettokens`，开发版 `wails dev` 使用同一 lock，会被 Wails 判定为第二实例并正常退出，表现为构建完成后 `Development mode exited`。
