## Sidecar 账号归因卡片设计修订

- `20260514-sidecar-usage-account-attribution` 设计稿收敛为桌面 Wails 工作台方案，不考虑移动端适配；页面保持固定 1180px 画布，窄窗口允许横向滚动。

- quota 区域支持多个窗口并列展示，例如 `WEEKLY / DAILY / 5H` 或 `DAILY / MONTH`，不再假设单个额度窗口。
