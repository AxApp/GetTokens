## Route Guard DSL Engine Evaluation

- 新建 space：docs-linhay/spaces/20260618-route-guard-dsl-evaluation/，用于评估“用户对单个账号配置路由守卫规则”是否可升级为 DSL / 规则引擎。
- 评估结论：建议升级为 sidecar-owned typed rule engine，但第一期不开放用户自由 DSL；用户侧应先提供受限规则构建器，编译为可验证、可解释、可版本化的 typed rule schema。
