## 账号池解除限流后的今日用量口径修复
- 用户在账号池卡片标注“今日请求 / 今日 TOKEN”，指出解除限制后昨日用量仍留在今日统计里。
- 根因：`RateLimitGuard` 无限流规则分支把 `usageSummary.requestCount / totalTokens` 直接标成“今日”，但 usage summary 来自 `GetSidecarUsageAttribution({ window: '24h', bucket: '1h' })`，会包含本地昨日但仍处在 24h 窗口内的 bucket。
- 修复：新增 `buildAccountTodayUsageTotals()`，按本地日历日过滤 `trafficBuckets` 后汇总当天请求与 token；卡片无限制分支和活动条改用该当天值。
- 验证：`node --test src/features/accounts/tests/accountUsage.test.mjs src/features/accounts/tests/rateLimit.test.mjs`、`npm run typecheck` 通过。
- 沉淀审计：这是账号池 route guard 展示口径的局部修复，已写入 `docs-linhay/spaces/20260611-route-guard-token-window-failed-usage/README.md`；不新增 skill 或 AGENTS 规则。
