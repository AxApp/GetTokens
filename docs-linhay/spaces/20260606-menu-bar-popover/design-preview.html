收窄原则

menu bar popover 只展示额度和余额，隐藏账号类型教学、模型映射和路由解释。类型差异只影响数据标签，不占用首屏注意力。

Quota 5H / 7D / vendor 只列风险账号，按剩余比例升序；正常账号不逐个展示。
Balance USD / CNY / vendor 展示可读余额源；无余额能力的账号不显示，不写“未知”。
Warnings empty / low / stale 只保留影响使用的状态，例如额度空、低于阈值、余额源 stale。
Actions open / refresh 完整账号类型、模型、路由和编辑能力统一回主窗口。
