Implementation boundary

Rate limit state is not a new card type.

  • 扩展 `AttributionCard` 的区域配置，而不是复制一张限流卡。
  • Codex full/compact 都要显示超限 chip；compact 只隐藏归因区域。
  • 同一组卡片继续走三列轨道，禁止两张 Codex 卡被拉伸成半屏宽。

03 / Detail Modal

规则 CRUD 放在详情页的 Route Guard Section

限流规则不是 API key 基础配置字段。它应该在 Management 与 Verification 之间形成独立 section，展示 evaluator 状态、规则行和当前窗口用量。

Redesign notes

Modal 必须回答三个问题

  • 这条规则是否会让账号退出路由候选。
  • 当前状态来自哪次 evaluator 快照，是否滞后。
  • 保存后是否立即触发 EvaluateNow，而不是等下一个 30s tick。
