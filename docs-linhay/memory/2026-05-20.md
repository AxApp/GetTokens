## Claude Code 账号列表完整闭环

- 决策：Claude Code 账号列表按 Codex 账号列表等价业务闭环推进，但筛选条件固定为 `supportedFormats.includes("anthropic")`，不按 provider 名称判断。
- 实现：页面复用 Codex 请求顺序、账号详情和路由探测组件；拖拽排序写回 `UpdateAccountPriority`，启停写回 `SetAccountDisabled`。
- 模型映射：OAuth/auth-file 走 `UpdateOAuthModelAliases(channel="claude")`；openai-compatible 走 `UpdateOpenAICompatibleProvider(models)`；codex-api-key 新增 `UpdateCodexAPIKeyConfig(models)` 持久化并同步 sidecar。
- 后端：新增 `ProbeClaudeCodeAccountRouting`，用 Anthropic Messages `POST /v1/messages` 最小请求探测，复用 `X-GetTokens-Route-*` header 和 recent request delta 识别命中账号。
- DTO：`AccountRecord` 补 `apiKeys`、`headers`、`models`，用于 Claude Code 账号详情模型映射读取、保存和远端模型查询。
- 验证：`go test ./...`、`npm --prefix frontend run typecheck`、`npm --prefix frontend run test:unit`、`npm --prefix frontend run build` 通过；agent-browser 预览页面和路由探测弹层错误为空，截图已归档到 space。
