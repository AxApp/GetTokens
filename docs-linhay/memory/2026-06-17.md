# 2026-06-17

## DeepSeek 单卡刷新入口图标化修复

- 用户截图反馈 DeepSeek 卡片处于“等待检测”时，右上角显示三点菜单而不是刷新按钮；随后明确底部也应是刷新按钮，而不是纯文本“同步运行状态”。
- 根因：`AccountCard.tsx` 的 `topActions` 固定渲染账号操作菜单；单卡 refresh/runtime sync 动作只出现在 footer 文本按钮。
- 修复：右上角和 footer 刷新动作都改为 `RefreshCw` 图标按钮，复用既有 `buildAccountCardRefreshAction()` 的文案、禁用态和 `onRefreshQuota(account)` 链路；三点菜单继续保留复制、重登、禁用、删除等账号操作。
- 验证：`node --test frontend/src/features/accounts/tests/accountCardInteractions.test.mjs`、`node --test frontend/src/features/accounts/tests/accountCardLayout.test.mjs`、`npm --prefix frontend run typecheck` 通过；无头 preview DOM 断言确认 22 张账号卡 footer 都是刷新图标按钮，且底部文本“同步运行状态/刷新额度”消失，并归档截图到 `docs-linhay/spaces/20260606-account-runtime-sync/screenshots/20260617/accounts/20260617-account-card-refresh-icons-after-v02.png`。
- 沉淀审计：这是账号卡 UI 入口一致性的小修，已写入 `20260606-account-runtime-sync` space 和 memory；暂不升级 skill 或 `AGENTS.md`。
