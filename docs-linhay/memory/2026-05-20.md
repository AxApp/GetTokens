## 账号卡额度内部刷新态

- 根因：单账号刷新额度时 `refreshCodexQuota` 会把已有成功 quota 覆盖为纯 loading，`buildQuotaDisplay` 因而返回空窗口，导致额度条消失并切换到整段 loading 占位，卡片高度抖动。
- 修复：quota state 增加 `refreshing` 语义；已有 quota 刷新时保留旧窗口，仅在 `QuotaBars` 条形槽内部叠加 16px 高的刷新骨架；首次无 quota 时仍使用原 loading 占位。
- 设计系统：`Design System/业务组件/账号卡片` 增加 `QuotaBarsRefreshing` story，`CardSections` manifest 增加 `quota-refreshing` 状态。
