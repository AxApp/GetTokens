## cc-switch Codex Skills / MCP 源码复核修正

- Codex MCP 真实模型以 `command` / `url` 推断 transport，不使用 `type = "stdio/http/sse"` 作为持久化字段；远端 transport 是 `streamable_http`。
- Codex MCP 写回字段应使用 `http_headers`、`env_http_headers`、`bearer_token_env_var`，并拒绝 inline `bearer_token`。
- Codex Skills roots 不止 `$CODEX_HOME/skills`，还包括 `$HOME/.agents/skills`、`$CODEX_HOME/skills/.system`、`/etc/codex/skills`、repo `.codex/skills` 和 project root 到 cwd 之间的 `.agents/skills`。
- Skill 首期应优先做“扫描 + 启用/禁用”，启停通过 `[skills]` / `[[skills.config]]`；启用语义是移除禁用 override，不是写入 `enabled = true`。
