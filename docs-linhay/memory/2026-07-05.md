## Wails Dev 动态页面加载断连修复

- 根因：`App.tsx` 中各页面使用 React `lazy()` 动态 import；Vite dev server 短暂断连时，浏览器会把同一模块 specifier 的失败缓存成 rejected promise，导致 `StatusPage.tsx` 这类页面在服务恢复后仍抛出 `Failed to fetch dynamically imported module`，且原树只有 `Suspense` 没有 error boundary。
- 处理：新增 `lazyPage()`，dev 模式下首次动态 import 失败后改用带 `?retry=` 的源文件路径重试，绕过失败缓存；同时新增 `PageErrorBoundary`，重试耗尽时提供可 reload 的页面级 fallback。`index.html` 显式声明 `favicon.svg`，避免浏览器默认请求 `/favicon.ico` 产生 404 噪声。
- 验证：`node --test src/features/design-system/storyCatalog.test.mjs`、`npm run typecheck`、`npm run build` 通过；无头浏览器强制第一次 `StatusPage.tsx` 请求 `ERR_CONNECTION_REFUSED` 后，第二次 retry 成功加载状态页，未显示错误页；正常打开 `#frame=status` 未再出现 `favicon.ico`、动态 import 或相关 `ERR_CONNECTION_REFUSED`。
