# 2026-06-01

## gt deep link 账号导入定稿

- deep link 一期收敛为账号与账号配置导入：只保留 `gt://app/v1/import?payload=<base64url-json>` 这一 GetTokens 私有 deep link 入口。
- 明确取消导入 POST 计划：不新增 `/v0/management/gettokens/account-imports/preview` 或 `/v0/management/gettokens/account-imports`。
- 明确移除旧入口兼容：不支持 `gettokens://v1/import`，不支持旧 `resource=account/codex-config/codex-setup`。
- 明确移除 cc-switch 支持：不支持 `gt://v1/import`，不解析 cc-switch `resource=provider/mcp/prompt/skill`。
- 私有 payload 使用 `schema=gettokens.import.v1` 和 `accounts[]`，每个账号直接贴近 `cliproxyapi.AccountWriteRequest`，只额外允许 `ref` 做结果关联；不再引入 `documents`、`operations`、`codexLocal`。
- 多账号导入不设账号数量硬上限，但需要 decoded payload 字节上限、逐账号结果、`continue_on_error`、成功保留失败不回滚。
- 本期不写 `CODEX_HOME/auth.json`、`CODEX_HOME/config.toml`、Claude Code settings，也不导入 MCP、prompt、skill、usage script、remote config 或 headers query。
- 规格文档落位：`docs-linhay/spaces/20260528-cc-switch-one-click-import/plans/20260601-gt-deeplink-account-import-technical-spec-v01.md`。

## gt deep link 账号导入实现

- 已按新规格完成一期施工：`wails.json` URL scheme 注册 `gt` 与本地冒烟别名 `gt-dev`，启动参数和 single instance 队列消费 `gt://` / `gt-dev://`；`gt-dev://` 语义与 `gt://` 一致，仅用于本地测试入口隔离。
- 后端 deep link 实现已收敛为 `gt://app/v1/import?payload=<base64url-json>`，解析 `schema=gettokens.import.v1` 和 `accounts[]`，拒绝旧 `gettokens://v1/import`、`gt://v1/import`、路径式 payload、`documents/operations/codexLocal`、`account_key` 等禁用字段。
- Apply 路径不再写 Codex / Claude Code 本地配置，逐账号编译为 `cliproxyapi.AccountWriteRequest` 并调用 sidecar `POST /v0/management/accounts`；支持多账号、逐账号结果、`continue_on_error`、openai-compatible 重名自动 `#2/#3` 和 auth-file normalize。
- 前端 deep link 入口改为独立 `DeepLinkAccountImportConfirm` 批量账号确认页，移除旧 `DeepLinkCodexApplyAdapter` 与 `AccountLocalCliApplyConfirm` 的 deep link adapter props。
- 验证通过：`go test ./internal/wailsapp -run DeepLink -count=1`、`go test . -run TestWailsConfigRegistersProdAndDevDeepLinkSchemes -count=1`、`go test ./... -count=1`、`node --test frontend/src/features/accounts/tests/accountLocalCliMapping.test.mjs`、`npm --prefix frontend run typecheck`、`npm --prefix frontend run test:unit`、`./scripts/wails-cli.sh build`、`docs-linhay/scripts/check-docs.sh`、`git diff --check`。
- 打包产物 `Info.plist` 已确认同时注册 `gt` 与 `gt-dev`；执行 `open -g gt-dev://...` 时未抢前台，但 LaunchServices 命中了机器上既有的另一个 dev build，因此本轮只把它计为系统 scheme 可解析冒烟，不计为当前 worktree 新 build 的完整桌面 UI 冒烟。
