交互重构 01：状态不再散落

验证摘要从右上角小卡移到左侧 Identity Rail；运行操作集中到右侧 Run Inspector。用户扫一眼左右两栏就能判断“这个账号是谁、现在能不能用、为什么不能保存”。

交互重构 02：模型目录变成工作表

现有模型、本地别名、远端候选、应用动作合并到一个表格语境中，避免“拉取远端模型”按钮和模型行编辑彼此割裂。

交互重构 03：底部是唯一保存门禁

footer 只做一件事：解释当前是否能保存以及为什么。优先级保持现有业务：proxyRouteError > rateLimitDirty > verifyState.message > idle。
