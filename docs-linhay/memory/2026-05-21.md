## Codex OAuth 本地应用 tokens 结构修正

- 根因：GetTokens / sidecar 会把 Codex auth-file 归一化成扁平结构（`type=codex`、`access_token`、`id_token`、`refresh_token`、`account_id`），并移除 nested `tokens`；账号卡 OAuth 应用到 Codex 的后端写入逻辑只识别原生 Codex nested `tokens`，导致真实写入时报“Codex OAuth auth.json 缺少 tokens”。
- 修正：`buildRelayCodexOAuthAuthJSON` 现在同时接受原生 nested tokens 与 sidecar flat auth-file，写入 `CODEX_HOME/auth.json` 前统一转回 Codex 原生结构：`auth_mode=chatgpt`、`tokens.id_token/access_token/refresh_token/account_id`，并移除根部 API key / flat token 字段。
- 验证：新增 sidecar flat auth-file 回归测试；`go test ./internal/wailsapp` 通过。
