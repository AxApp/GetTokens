## 会话管理标题降噪
- 用户在 `#frame=codex&workspace=session-management` 标注会话列表，指出每条开头都是 `# AGENTS.MD INSTRUCTIONS FOR <...`，要求优化方案并按推荐落地。
- 根因：会话标题生成只记录首条 `user` 文本和最近 primary 文本；当 AGENTS.md / permissions / environment / 浏览器 evidence 这类启动上下文以 `user` 角色进入 JSONL 时，会抢占 `title`。
- 修复：新增低信号 preamble 判定与 `sessionTitleSignals` 候选器，生成 `displayTitle/titleSource/titleConfidence/primaryIntent/lastOutcome/hasInstructionPreamble`；Codex 与 Claude Code parser、Wails root DTO/mapper、frontend model、dev bridge 同步字段；会话列表和详情主标题优先读 `displayTitle`，旧磁盘 snapshot cache 读取/写入时同步归一化。
- 追加 UI 收敛：会话列表卡片移除标题下方的同源 summary，保留主标题并改为两行截断，避免“标题/摘要”上下重复。
- 验证：`go test ./internal/wailsapp -run 'TestCodexSessionSnapshot(SkipsAgentsPreambleForDisplayTitle|ParsingSanitizesDerivedTitle)|TestGetCodexSessionManagementSnapshotGroupsProjectsAndStatuses|TestGetCodexSessionDetailMasksSensitiveTextAndKeepsMessageRows|TestGetClaudeCodeSessionManagementSnapshotScansMainSessionsAndSkipsSubagents'`、`go test ./...`、`node --test frontend/src/features/session-management/model.test.mjs`、`npm --prefix frontend run typecheck`、`npm --prefix frontend run build`、`node --check frontend/dev/sessionManagementDevData.js`、`git diff --check` 均通过。
- 浏览器说明：手动触发全量 refresh 在本机会话量下超过 Playwright 120s；已通过后端缓存归一化测试与 dev bridge 旧快照归一化覆盖旧数据路径。若现有 localhost 页面仍显示旧标题，优先重载 dev server 以清掉进程内模块缓存。
