## 会话管理读取性能

## 会话详情页优化
- `GetCodexSessionDetail` / `GetClaudeCodeSessionDetail` 已改成按会话文件指纹读写磁盘缓存，并在 `App` 内保留内存缓存；文件未变化时重复打开详情会直接命中缓存。
